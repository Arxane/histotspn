=========================================

Updated for BiomedCLIP feature extraction, seed-based TSPN, ABMIL + LMF
multimodal fusion, and multi-loss TSPN training.

# PIPELINE

Stage 0: Train classifier on real HE + real IHC
Stage 1: Train TSPN with frozen classifier distillation
Stage 2: Jointly fine-tune TSPN + LMF classifier
Evaluation: Test final pipeline
Analysis: Validate synthetic IHC feature distributions

--stride 512

The pipeline performs:

## Stage 0

Real HE + real IHC
↓
ABMIL per modality
↓
Low-rank multimodal fusion (LMF)
↓
MLP classifier

## Stage 1

HE
↓
TSPN
↓
Synthetic IHC
↓
Frozen Stage-0 LMF classifier

Training objective:

L =
λ_MMD L_MMD

* λ_SWD L_SWD
* λ_MM  L_MM
* λ_KL  L_KL
* λ_CE  L_CE

## Stage 2

HE
↓
TSPN → Synthetic IHC
↓
ABMIL + LMF classifier

TSPN and classifier are jointly trainable.

Training objective:

L =
λ_CE  L_CE

* λ_MMD L_MMD
* λ_SWD L_SWD
* λ_MM  L_MM

================================================================================
STAGE 0: TRAIN CLASSIFIER ON REAL HE + REAL IHC
===============================================

## Description:

Train the real-modality classifier using real H&E and real IHC feature bags.

The classifier architecture is:

HE patches
↓
Linear projection
↓
ABMIL
↓
HE representation

IHC patches
↓
Linear projection
↓
ABMIL
↓
IHC representation

HE representation + IHC representation
↓
Low-rank multimodal
fusion (LMF)
↓
MLP
↓
class logits

## QUICK START

python train_classifier_real.py 
--data-root BCI_dataset 
--output-dir artifacts/classifier_real 
--eval-split validation 
--device cuda

## FULL CONTROL

python train_classifier_real.py 
--data-root BCI_dataset 
--eval-split validation 
--output-dir artifacts/classifier_real 
--patch-size 512 
--stride 512 
--min-tissue-fraction 0.5 
--conch-batch-size 32 
--epochs 20 
--early-stopping-patience 5 
--early-stopping-start 1 
--learning-rate 1e-4 
--weight-decay 1e-4 
--classifier-layers 2 
--classifier-dim 512 
--classifier-hidden 256 
--lmf-rank 16 
--lmf-output-dim 512 
--device cuda

## LMF PARAMETERS

--lmf-rank 16
Rank of the low-rank fusion decomposition.

--lmf-output-dim 512
Output dimensionality of the fused representation.

The LMF module uses:

HE factor:
(rank, dim + 1)

IHC factor:
(rank, dim + 1)

Output factor:
(rank, output_dim)

## OUTPUT

artifacts/classifier_real/classifier_checkpoint.pt
Trained LMF classifier + architecture configuration.

artifacts/classifier_real/history.json
Epoch-level training and validation metrics.

================================================================================
STAGE 1: TRAIN TSPN WITH FROZEN CLASSIFIER DISTILLATION
=======================================================

## Description:

Train the seed-based TSPN to generate a fixed-size synthetic IHC feature
set from H&E features.

Input:
Variable-size HE feature bag
(N, 512)

Output:
Fixed-size synthetic IHC feature bag
(64, 512)

## IMPORTANT:

64 = number of synthetic IHC feature vectors.
512 = dimensionality of each feature vector.

The Stage-0 LMF classifier is frozen and acts as the teacher.

## STAGE 1 OBJECTIVE

L_TSPN =
λ_MMD L_MMD

* λ_SWD L_SWD
* λ_MM  L_moment
* λ_KL  L_KL
* λ_CE  L_CE

## Losses

MMD
Matches synthetic and real IHC feature distributions using
multiple Gaussian kernels.

SWD
Sliced Wasserstein distance between synthetic and real IHC
feature distributions.

Moment matching
Matches feature distribution statistics using mean and covariance.

KL distillation
Matches predictions from the frozen real-IHC teacher and
synthetic-IHC student.

Classification
Cross-entropy between synthetic-IHC classifier predictions
and the ground-truth slide label.

## QUICK START

python train_tspn.py 
--data-root BCI_dataset 
--classifier-checkpoint artifacts/classifier_real/classifier_checkpoint.pt 
--output-dir artifacts/tspn_distill 
--eval-split validation 
--device cuda

## FULL CONTROL

================================================================================
STAGE 2: JOINT FINE-TUNING
==========================

## Description:

Jointly fine-tune:

1. TSPN
2. ABMIL + LMF classifier

The classifier is initialized from Stage 0.
The TSPN is initialized from Stage 1.

## STAGE 2 ARCHITECTURE

HE feature bag
│
├──────────────────────────────┐
│                              │
▼                              ▼
TSPN                         HE ABMIL
│                              │
▼                              │
Synthetic IHC                        │
│                              │
▼                              │
IHC ABMIL                        │
│                              │
└──────────────┬───────────────┘
▼
LMF
│
▼
MLP
│
▼
logits

## STAGE 2 OBJECTIVE

L_joint =
λ_CE  L_CE

* λ_MMD L_MMD
* λ_SWD L_SWD
* λ_MM  L_moment

The real IHC feature bag is used as the target distribution for
MMD, SWD, and moment matching.

KL distillation is not required in Stage 2 because the classifier
is no longer frozen.

--eval-split validation 
--device cuda

## LMF PARAMETERS

The classifier architecture should be reconstructed from the
Stage-0 classifier checkpoint.

Recommended configuration:

--lmf-rank 16
--lmf-output-dim 512

## LOSS WEIGHTS

λ_CE:
Classification objective.

λ_MMD:
Synthetic/real IHC distribution matching using MMD.

λ_SWD:
Synthetic/real IHC distribution matching using sliced
Wasserstein distance.

λ_MM:
Synthetic/real IHC mean/covariance matching.

================================================================================
NOTES
=====

1. BiomedCLIP downloads on first run (~750 MB).

   Set HF_TOKEN in .env if required to avoid download/rate-limit issues.

2. GPU memory:

   Typical training requires approximately 15 GB GPU memory.

   Reduce --conch-batch-size if GPU memory is insufficient.

3. Dataset split:

   Train:
   90% of paired IDs.

   Validation:
   10% of paired IDs, stratified by label, seed=42.

   Test:
   Held-out BCI_dataset/*/test split.

4. Do not use the test set for model selection.

   Use validation for:
   - early stopping
   - checkpoint selection
   - hyperparameter tuning

   Use test only for final reporting.

5. Variable-size bags are supported.

   HE:
   (N, 512)

   Real IHC:
   (M, 512)

   TSPN:
   (64, 512)

6. MMD, SWD and moment matching compare feature distributions.

   They do not require one-to-one correspondence between synthetic
   and real IHC patches.

7. Stage 1 classifier is frozen.

   The classifier remains in evaluation mode while gradients from
   synthetic-IHC predictions propagate through the frozen classifier
   back into TSPN.

8. Stage 2 jointly trains TSPN and the LMF classifier.

   Separate learning rates are recommended:

   ```
   TSPN:
       1e-5

   Classifier:
       1e-4
   ```

9. Loss coefficients are not directly comparable across losses.

   MMD, SWD, moment, KL and CE can have different raw magnitudes.

   Inspect the individual loss values and weighted contributions
   before selecting final coefficients.

10. LMF architecture must remain consistent between Stage 0 and
    later stages.

    Recommended:

    ```
    lmf_rank       = 16
    lmf_output_dim = 512
    ```
